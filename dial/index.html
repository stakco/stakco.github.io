Surface Dial HID Mapping Information:

The Microsoft Surface Dial uses the following HID characteristics:

  • Vendor ID: 0x045E (Microsoft)
  • Usage Page: 0x01 (Generic Desktop)
  • Usage: 0x0E (System Multi-Axis Controller)
  • Transport: Bluetooth Low Energy
  • Input Reports: Contains rotation delta and button state
  • Rotation: Reported as signed relative values
  • Button: Press/release events for the dial press action

This implementation uses the WebHID API to access raw HID reports from the Surface Dial, parse the rotation and button data, and map it to a virtual dial interface.
